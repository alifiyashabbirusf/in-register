    How it works

    The number is the countdown

    One giant number, readable from across the room. It gets bigger as the deadline gets closer, until it runs off the screen.

    The gap is the pressure

    In screen printing, colours that miss each other are out of register. Here the miss shrinks by a fixed step each day, so you can feel the deadline closing before you read anything.

    A plan you can read in a second

    Today's task is the headline. The milestones still ahead sit under it in date order, and each one drops off the screen once its date has passed, so the number grows as the list empties.

    Loud, then quiet

    On the day, the screen floods red and says GO. Afterwards it settles to a single tick, like a notification.

    What Gemini did

    The deadline is real: a group architecture assignment due 30 November, with a seven-section report, a slide deck and a recorded presentation. Gemini did five jobs, and each one is on the screen.

    1. Planned backward

    From the brief, Gemini worked back from 30 November to five milestones with a buffer day, and named the biggest risk: hand-offs between sections.

    2. Wrote the daily task

    It turned the milestones into 14 tasks of 22 characters or fewer, one per day. The lock screen shows that day's task as its headline.

    3. Critiqued the design

    I uploaded a screenshot and asked what would fail on a real iPhone. I tested each answer on my phone, kept two and declined two.

    4. Generated the lock screen

    From my written brief, with exact colours, fonts and spacing, Gemini generated the lock screen over four rounds of my corrections, then two more rounds on the refined design.

    5. Set the reminders

    It added every milestone to my Google Calendar and set a daily 8 am reminder that sends me that day's task.

    How the lock screen was made

    I wrote the brief from my print background. Gemini generated each version, and I corrected what it got wrong. The fourth round is the lock screen I am entering. The studio at the top of this page carries the same design through every day of the countdown.

    Set up the daily swap on an iPhone

    1. Press Save every day as a zip. In Files, tap the zip to unzip it.
    2. In Shortcuts, open Automation, tap +, choose Time of Day: 6:00 am, Daily, Run Immediately.
    3. Add Format Date: Current Date, Custom, yyyy-MM-dd, with no spaces.
    4. Add Get File from Folder: pick the unzipped folder, path = Formatted Date + .png.
    5. Add Set Wallpaper Photo: Lock Screen. Turn off Show Preview and Crop to Subject.
    6. Tap play to test. If a file is "not found", the error shows the name it looked for.

    Just want today's? Press Save this day, then set it in Settings > Wallpaper with Extend Wallpaper off.
